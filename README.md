# 🧪 TermuxLabLogger

**TermuxLabLogger** is a Python-based digital lab notebook that allows you to record and manage experiments easily.  
It works completely **offline** and is fully compatible with **Termux (Android)**, Linux, and desktop systems.

---

## 🚀 Features

- Add new experiments
- Automatic date & time logging
- Record input, observation, and result
- View all saved experiments
- Local JSON file storage
- Offline-friendly, no internet required

---

## 🧠 Use Cases

- Science lab experiments
- Electronics testing logs
- Coding test records
- Student projects
- Research documentation

---

## 🛠 Requirements

- Python 3.x
- Termux / Linux / PC

No external Python libraries required.
